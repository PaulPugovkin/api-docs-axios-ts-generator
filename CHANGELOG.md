# Changelog

Все заметные изменения в проекте будут задокументированы в этом файле.

## [1.2.0] - 2026-05-24

### Изменения
- ⚡ **Сборщик tsup**: исходные файлы теперь собираются в один минифицированный `dist/index.js` (16 KB, было 25+ файлов)
- ⚡ **Убран `node-fetch`**: используется нативный `fetch` Node.js 18+, убрана зависимость
- ⚡ **axios → peerDependencies**: пакет больше не тянет axios при установке (~2 MB экономии)
- 🎯 **Generated code**: `import type` вместо `import` для типов — улучшен tree-shaking
- 🗑️ **Удалён мёртвый код**: папка `collect-genereted-files` (с опечаткой, нигде не использовалась)
- 🏗️ **Добавлен `tsconfig.json`** и `tsup.config.ts`
- 📦 **Обновлён `package.json`**: `main` → `dist/index.js`, `bin` → `./dist/index.js`, `files` → только `dist` + `src/scripts` + `src/templates`
- 🔧 **`engines.node`**: поднято до `>=18` (breaking change)
- 🚀 **CI**: добавлен GitHub Actions workflow для публикации при пуше тега `v*`
- 🔐 **`.env`**: удалён из репозитория (NPM токен)

## [1.0.0] - 2026-02-10

### Добавлено
- 🎉 Первая версия генератора API клиента
- ✨ Поддержка конфигурационных файлов TypeScript
- 🏷️ Фильтрация по тегам (include/exclude/prefix)
- 📁 Режимы генерации: один класс или несколько по тегам
- ⚙️ Автоматическая генерация конфигурации axios
- 🎯 Поддержка распыления пользовательских конфигураций axios
- 📝 JSDoc комментарии для методов
- 🔄 Обратная совместимость с CLI аргументами
- 📦 Подготовка к публикации на npm

### Основные возможности
- Генерация TypeScript интерфейсов из OpenAPI схем
- Генерация классов axios с методами API
- Гибкая конфигурация через TypeScript файл
- Фильтрация по тегам (include/exclude)
- Режимы группировки: 'tag' | 'all' | 'path'
- Режимы генерации классов: 'single' | 'multiple'
- Кастомные функции именования
- Генерация конфигурации axios с перехватчиками
- Поддержка распыления пользовательских конфигураций
- Автоматическая генерация index файлов

### Конфигурация
- `apiDocsUrl` - URL для загрузки OpenAPI спецификации
- `apiDocsPath` - Локальный путь к файлу OpenAPI спецификации
- `outputDir` - Директория для вывода сгенерированных файлов
- `tags.include` - Теги для включения
- `tags.exclude` - Теги для исключения
- `tags.prefix` - Префикс тегов
- `groupBy` - Режим группировки методов
- `classMode` - Режим генерации классов
- `naming` - Кастомные функции именования
- `imports` - Настройки импортов
- `options` - Опции генерации
- `axios` - Настройки axios

### CLI опции
- `--config` - Путь к конфигурационному файлу
- `--api-docs-url` - URL для загрузки OpenAPI документации
- `--api-docs-path` - Локальный путь к файлу OpenAPI документации
- `--output-dir` - Директория для вывода сгенерированных файлов
- `--clean` - Очистить директорию вывода перед генерацией
